# 모바일 자동매매 연구실 v3

사용자가 제공한 차트 패턴/조건검색 자료에서 반복되는 아이디어를 수치화한 테스트 버전입니다.

## 전략
- 종합 점수형
- N자·눌림목
- 추세전환 스윙
- 볼린저 돌파
- 중장기 추세
- W바닥 근사

## 점수
- 20/60일 추세: 20
- 60/112/224 장기 정배열: 20
- 거래량 증가: 20
- 20일 고가 돌파: 20
- 20일선 눌림 후 회복: 10
- Bollinger(40,2) 상단 돌파: 10

## 모바일
Streamlit Community Cloud 등에 배포하면 휴대폰 브라우저에서 사용 가능합니다.
홈 화면에 추가하면 앱처럼 열 수 있습니다.

## 주의
실제 NH투자증권 주문은 포함하지 않습니다.
백테스트 결과는 미래 수익을 보장하지 않습니다.
